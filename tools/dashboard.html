읽기 전용 모드. 프레임을 한 개도 보내지 않는다. 명령을 쓰려면 --read-only 없이 다시 띄운다 (단 ak45_ctrl·ROS2 노드를 먼저 끈다).

임의 프레임 전송 — AK45 가 아닌 장치용 (예: CAN ID STM32 PWM 보드)

CAN ID 는 STM32 보드이고 PWM 으로 모터를 돌린다 — AK45 서보 프로토콜이 아니다. 그래서 아래는 페이로드를 해석하지 않고 그대로 보낸다. 입력·표시 전부 10진수다 (16진수로 넣고 싶으면 0x 를 붙인다).
⚠️ 검사가 하나도 걸리지 않는다 — 목표각 상한(S1)도, 모터 에러 차단(S4)도 우회한다. 재송신도 하지 않는다(1회 전송). AK45 모터에 위치 명령을 이걸로 보내면 100ms 뒤 모터 쪽 타임아웃으로 홀딩 토크가 풀린다 — 모터는 위 카드로 제어해라.

모터 (ID 0~9 개별)

모든 수치는 10진수다. 회색 작은 숫자는 CAN 원시 정수값(int16)이다. 전송은 100ms 주기로 자동 재송신된다 — 멈추면 홀딩 토크가 풀린다.
