현재 하드웨어 상태 (2026-08-27 실측)
  - CANable 어댑터 인식됨, 인터페이스는 can0 으로 바로 잡힌다
  - 버스에 모터 1대뿐 : ID 0x02  (ID 1,3,4,5,6 은 없음)
  - 모터 0x02 : 위치 -9.8도, 전류 0A, 에러 없음, 온도 50도까지 상승했음
  - 피드백 50Hz 정상 수신 ("Send status over CAN" 이미 켜져 있음)

  sudo ip link set can0 up type can bitrate 1000000

  cd ~/바탕화면/Can
  make clean && make               # clean 필수 (아래 주의 1)

--------------------------------------------------------------------
 [터미널 1] 모니터  ← 먼저 열기
--------------------------------------------------------------------

  cansniffer can0

  ID별로 한 줄씩 고정되어 값만 실시간 갱신된다 (candump 는 50Hz로 화면이 쓸려 올라감).
  종료는 q.

  00002902 줄의 8바이트 해석 :

     FF 9E   00 00   00 00   32   00
     └─┬─┘   └─┬─┘   └─┬─┘   └┬┘  └┬┘
      위치     속도    전류   온도  에러
     x0.1deg  x10ERPM x0.01A   C   0=정상

     FF 9E = int16 -98  -> -9.8 도
     00 64 = int16 100  ->  10.0 도

  그냥 원본 프레임을 보고 싶으면 :
     candump can0
     candump can0,00000402:1FFFFFFF     # ID2 위치명령(mode 4)만 필터


--------------------------------------------------------------------
 [터미널 2] 제어
--------------------------------------------------------------------

  cd ~/바탕화면/Can
  ./ak45_ctrl 2>/dev/null            # 2>/dev/null 은 워치독 도배 숨김 (주의 2)

  프롬프트가 뜬다 :
     > 목표각도 입력 (예: 30 / 30 20 10 (최대 6개), q=종료):

  ★ 입력은  "ID1값 ID2값"  순서다. ID2가 목표이므로 값 2개를 줘야 한다.


  1단계 — 기준축 판별 (반드시 먼저)
  ---------------------------------
     0 10

     ID2가 -9.8도 -> 10도 로 이동 (약 20도).
     터미널1에서 2902 앞 2바이트가 FF 9E -> 00 64 로 바뀌는지 확인.

     ** 출력축이 실제로 몇 도 돌았는지 눈으로 본다 **

       약 20도 돌았다      -> 출력축 기준. 360은 1회전이다. 보내지 말 것
       거의 안 움직였다     -> 모터축 기준. 360 = 출력축 약 10도. 안전


  2단계 — 판정이 "모터축 기준" 일 때만
  -----------------------------------
     0 360

     Enter 만 누르면 목표가 즉시 갱신된다. 창을 새로 열 필요 없다.


  되돌리기 / 종료
  ---------------
     0 -9.8      원래 위치로 복귀
     q           안전 정지(Current Brake 0A) 후 종료   (Ctrl+C 도 동일)


--------------------------------------------------------------------
 천천히 움직이고 싶을 때 (램프)
--------------------------------------------------------------------

  ak45_ctrl 은 램프가 없다. 목표를 주면 모터 최대 속도로 간다.
  계단식으로 천천히 가려면 ak45_ctrl 을 끄고 :

     ./ak45_ctrl_demo 0 10                            # ID2를 10도로, 1도/150ms
     ./ak45_ctrl_demo 0 360 --step=2 --interval=100   # 2도/100ms -> 약 19초

  단 demo 는 실행 중 값 변경이 안 된다. 바꾸려면 Ctrl+C 후 재실행.


--------------------------------------------------------------------
 주의사항
--------------------------------------------------------------------

 1) 빌드는 반드시 make clean 부터.
    Git에 커밋된 바이너리는 glibc 2.38 환경에서 링크된 것이라 이 PC(2.35)에서
      version `GLIBC_2.38' not found
    로 실행되지 않는다. make 만 돌리면 .o 타임스탬프 때문에 재링크를 건너뛰어
    안 고쳐진다.  ak45_demo 는 Makefile 타겟이 아닌 유령 바이너리이니 쓰지 않는다.

 2) ak45_ctrl 은 인자가 없어도 CAN 에 프레임을 쏟아낸다.
    위치 명령은 0건이지만, 워치독 분기가 피드백 없는 모터마다 100ms 주기로
    Current Brake 0A 를 보낸다. 지금은 5대가 없으니 5초에 약 200프레임,
    stderr 에 "[워치독] ID=0x.. 긴급 정지" 가 초당 50줄 나온다. 정상이다.
    0A라 모터는 움직이지 않는다.
    순수 읽기 전용이 필요하면 ROS2 노드를 쓴다 (실행 중 송신 실측 0프레임).

 3) 동시 실행 불가.
    ak45_ctrl / ak45_ctrl_demo / ROS2 노드  --  flock 때문에 셋 중 하나만 뜬다.
    (/tmp/ak45_ctrl.lock)
    cansniffer / candump 는 읽기만 하므로 같이 켜도 된다.
    누가 락을 잡고 있는지 :  fuser -v /tmp/ak45_ctrl.lock
    락 파일을 지울 필요는 없다. 프로세스 종료 시 OS 가 자동 해제한다.

 4) 종료하면 홀딩 토크가 풀린다.
    q / Ctrl+C 는 Current Brake 0A 를 보내 모터가 힘을 놓는다.
    출력축에 무게가 걸려 있으면 중력으로 떨어진다. 미리 받쳐둘 것.

 5) 360 은 소프트 리밋이 막아주지 않는다.
    SOFT_LIMIT_POS_DEG 가 정확히 360.0f 이라 그대로 통과한다.
    현재 -9.8도이므로 360 은 약 370도 = 1회전 이상 이동 명령이다.
    기준축이 판별되기 전에는 보내지 않는다.

 6) 온도를 계속 본다.
    전류 0A 상태에서 26 -> 50도까지 단조 상승했다. 상승이 멈추는지 확인하고,
    계속 오르면 전원을 내리고 배선/보드를 점검한다.


--------------------------------------------------------------------
 ROS2 로 상태만 보고 싶을 때 (모터 안 움직임)
--------------------------------------------------------------------

  [터미널 1]
     source /opt/ros/humble/setup.bash
     source ~/ros2_ws/install/setup.bash
     ros2 launch ak45_ros2 state_publisher.launch.py

  [터미널 2]
     source /opt/ros/humble/setup.bash
     source ~/ros2_ws/install/setup.bash
     ros2 topic echo /joint_states        # position 은 rad. 현재 -0.171 rad = -9.8도
     ros2 topic echo /diagnostics         # status 6개. ak45_2 만 level 0, 나머지 WARN
     ros2 topic hz /joint_states          # 50Hz

  ROS2 노드는 읽기 전용이다. 각도를 줘서 움직일 수 없다 (구독자 0개).
  "노드 띄우고 각도 주면 움직인다" 는 Phase 2 이고 아직 구현되지 않았다.

  velocity / effort 가 빈 배열인 것은 정상이다 (NPP·KT 미확정).
  원본 ERPM·전류·온도는 /diagnostics 의 KeyValue 에 들어 있다.
